
# Controlling a DC Motor

## Project Overview

This project demonstrates how an Arduino Uno can control a DC motor using an L293D motor driver. The Arduino sends digital signals to the motor driver, which provides the power needed to safely operate the motor.

Students learn how software can control physical movement through electronic components, introducing key concepts in robotics, automation, and embedded systems.

---

## Learning Objectives

By completing this project, students will:

- Understand the purpose of a motor driver
- Control a DC motor using Arduino
- Explore how digital outputs affect hardware
- Learn the relationship between software and physical systems
- Apply the Input → Processing → Output model

---

## Hardware Required

- Arduino Uno
- L293D Motor Driver
- DC Motor
- Breadboard
- Jumper Wires
- External Power Supply
- USB Cable
